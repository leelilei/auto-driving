# Proposal 张力复核与研究问题调整建议

2026-09-08。这是三个独立评审冻结后的综合判断，未回传给评审者。源文件为 proposal v4 与历史 Pilot 重算证据，非正式实验验收、非论文正文。本次暂停 API 试跑，未改写生效 proposal 或解锁论文写作。

## 总体判断

当前 v4 存在研究张力不足的风险，但“小型 POI 图、一个阈值、有限模型数”不是决定性缺点。核心问题在于方法容易被概括为换一个复核触发分数，而为什么应该这样触发、触发后是否有净收益，没有建立足够强的可检验证据。

v4 收敛掉训练仲裁器、多模态和车辆控制，提高了落地可行性，这部分应保留。但可执行性需要与问题的重要性同时成立，不能把完成工程清单当成完成研究。

## 独立评审共识与差异

三份评审一致认可受控后端、共享候选与同预算对照，也共同指出两个阻断项。

- S-M1，对应 R1-M1 / R2-M1 / R3-M2。方法新增部分主要处理结构一致后的软偏好分歧，主要指标和阈值选择却依赖硬约束 TSR。核心贡献与评价目标不匹配。
- S-M2，对应 R1-M2 / R2-M2 / R3-M1。已有 Pilot 没有建立值得调度的净复核收益。没有“值得花的钱”，调度这些钱的论文就缺少支点。

评审的附加侧重点不同。第一份指出 proposal 状态陈旧，第二份要求软偏好收益也有容忍边界，第三份强调用直观例子说明参数变化与决策变化的区别。未出现对扩大任务范围的支持，也未出现对当前方法已经成立的认可。

## 综合判断增加的一个核心问题

以下是综合阶段的分析，不冒充三份评审已独立形成的共识。

**决策风险与追加复核的收益不是一回事。** 当前 ΔU 衡量候选决策分歧，不直接衡量复核能改善多少。两个提示可能共同误读而产生小分歧；分歧很大时，原句也可能本就无法唯一确定精确权重，多调用一次只是再猜一个数。复核还可能改坏正确答案。

一个更有研究内容的问题是：语言解析中的不确定性，何时会造成有意义的规划损失，其中哪些又能通过一次复核得到改善？这可以拆成可独立失败的三个环节。

1. 语言分歧是否影响决策。大参数差异可能不改变最优路线，小差异可能跨过决策边界。但路线改变若近似等价，也不一定产生实质损失。
2. 受影响的决策是否能被复核纠正。需要按样本记录复核前后的实际变化，不能用 ΔU 替代真实净收益。
3. 能否把有限预算分配给有净收益的样本。与同预算语义分歧、结构保护和随机对照比较，检验实际质量与成本，而非仅比较触发率。

这不是通过改标题扩大外推范围。POI 仍是受控验证任务，跨任务通用性仍未证明，当前规则也不自动等于“最优复核策略”。

## 最小范围内增强方案的办法

保留现有解析、图、求解器与一次复核框架，先做机制诊断，而不是直接五模型扩量。

- 固定一批经审核的开发意图与真实候选输出，把同一个意图放入多种预先构造的图条件。改变候选地点之间的质量/距离取舍与时间余量，研究同一语言分歧何时被放大、何时无害；构图依据与采样规则预先记录，不能根据 Ours 表现挑图。
- 在结构一致子集，分别分析参数分歧、ΔU、复核前损失与复核净改善之间的关系。纠正、改坏、不变都保留，失败独立计数。
- 主方法贡献按受控 regret/偏好满足评价，TSR/GTSR 为不能牺牲的约束；Route Flip 作为诊断量。人造权重映射的敏感性必须报告，不能冒充真实用户效用。
- 如果 ΔU 能找到高损失、可纠正的样本，即使方法简单，也有清楚的经验贡献。如果只预测高风险却不能预测复核收益，再考虑用开发数据估计复核可纠正性；不是先堆一个复杂风险公式再寻找支持。
- 如果复核没有可靠净收益，应停止优化这套复核调度，重新讨论是否研究偏好不确定下的稳健规划。那将是新的研究方向，需要独立协议，不能把它伪装为原方法成功。

理想的会议研究链条是，一个被清楚证实的现象、一个可解释且可否定的原因、一种简单干预、公平比较和明确失效边界。增加模型数只能提供更多测量，不能替代这条链条。

## 对已有结果的使用边界

历史 Pilot 的 B0 与 Ours TSR 都为 0.975，Flip 从 0.1833 降至 0.1417，但 regret 从 0.001822 增至 0.002463。其数据语义和协议仍有局限，所以这些数字不能作为最终方法结论；它们足以提醒我们，“更稳定”可能没有带来“更好的路线”。不能靠继续强化稳定性叙述来解决这个矛盾。

“始终复核平均无收益”也不在逻辑上证明选择性复核永远无用。正负收益可能相互抵消。下一步真正需要确认的是，是否存在可复核改善的子集，以及可用信号能否在未见数据上辨认它。若连这种机会都没有，调度就无从谈起。

建议先讨论并冻结研究问题修订，再决定是否继续阶段三。既不退回庞大的 v3，也不按当前配置机械扩量。此建议不保证 EI 录用，本次也未完成最新相关工作的系统新颖性检索。
