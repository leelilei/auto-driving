## 2. 逐例发现与解释边界

原句证据的合同失败为F12、F27、F29：F12把P_A写入selection，F27/F29把INFEASIBLE写入selection。澄清后对应三例均返回合法规则结构。F12与F27的旧失败通过正确Direct回退获得最终成功；F29的原句证据失败回退后仍错，因此原始成功27与最终成功29的差额为2。

职责澄清没有自动修好全部规则理解：

- F29的C-E合法输出仍把departure误读为arrival，最终任务失败。
- F25的C-L也误读该字段，最终失败；O-L在此案例正确。
- 在澄清条件中，E相对L在F25赢一次、F29输一次。两组总分相同并非逐例行为完全相同。

因此“输出守约”与“规则理解正确”是两层不同问题。观察支持职责澄清有助于减少本轮接口越界，但不支持它必然提高任务成功，亦不支持事实表是纠正原句误读的必要信息。
