# 实验先行、验收后写作原则

生效依据：研究负责人在本轮明确要求“先把实验完全落地，认可之后，最后才去写论文”。日期：2026-09-07。

## 1. 强制顺序

实验协议与实现 → 数据审核与版本冻结 → 小规模准入 → 完整实验与统计/成本核查 → Codex 独立验收 → 研究负责人认可 → 论文写作。

当前阶段：**整改与实验验收中。论文写作未获准启动。** 执行者的自评 PASS、测试全过、pending 清零、自动生成的准入报告均不构成独立验收或负责人认可。

## 2. 实验阶段可以做什么

允许完成实验设计、文献核查、代码与测试、真实数据审核、数据版本与暴露管理、模型实验、失败分析、统计计算、内部结果表/诊断图、可复现归档及实验交接文档。执行范围仍以具体任务和既有授权为准。

在实验验收通过和负责人明确认可之前，不新增或改写论文摘要、正文、贡献与结论，不做投稿图包装、论文排版、压页、投稿材料或投稿操作。已有 paper/ 内容保留为未经实验验收的历史草稿，不删除，也不依据旧论文主张反向选择实验结果。实验设计文档不属于论文写作。

## 3. 打开写作阶段必须同时具备

1. 数据语义审核来源真实、可追溯；AI/规则预审明确标记，不能冒充人审。独立确认集无已暴露意图或等价簇；文本、标签和实际请求一一对应。
2. 冻结代码、模型/提示、数据、图、参数、指标版本；规定的基线、对照、消融和重复完成，缺失项有合理的预先范围修订。
3. 原始响应、完整失败/重试账本、成本与统计量可追溯。真实 run 可离线复现；输入缺失、版本不匹配或指标差异必须明确失败。
4. Codex 独立审查报告明确给出实验验收 PASS，所有阻断项关闭；通过只表示实验可信，不要求每项研究假设都得到正结果。
5. 研究负责人在看到该验收报告后明确认可进入写作；保存认可时间及所认可的实验版本。不能根据沉默、经过时间或执行者代签推断认可。

写作启动后若数据、核心指标或方法发生实质变化，应回到受影响的实验与验收步骤。不得为了匹配论文叙述删失败、选最好一次、调测试阈值或自动填写审核结论。
