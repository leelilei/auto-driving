# Luna全量诊断与下一轮开发压力实验设计

日期：2026-09-10。性质：S2补充开发实验设计，确认性实验与论文写作门禁仍为CLOSED。

## 1. Luna全量同协议诊断

目的：检验较短推理模型是否在当前任务上产生更多候选错误，以及决策对比报告是否在存在错误时比字段复核带来净纠正。该实验解释模型能力对当前天花板的影响，不用于替代Terra主模型。

固定条件：

- 模型：`gpt-5.6-luna`。FHL首轮因持续TLS错误形成独立`INCOMPLETE_NETWORK`证据，禁止进入方法分析；随后使用本地已认证模型目录明确列出该精确ID的xcode接口从零重跑。两个供应商的响应不拼接。
- 数据：已审核的`pilot_01`–`pilot_08`，32句，不增删样本。
- 图：`20260909_s1_graphs_v3`的aligned、tradeoff、time_sensitive三条件。
- 提示和方法：A、B、A2、A3、LLMAP direct、LLMAP CoT、Plain、Fields、Constraints、DARC，与DeepSeek八组诊断完全一致。
- 规模：8组×72=576个逻辑单元；自动重试0。schema失败计入结果，传输失败使run不完整。
- 回退：review schema失败时按有效A→有效B→失败；某句A/B无效导致的下游未调用必须形成账本记录。
- 并发：先进行1/2/4/8路小请求探针。实测仅1路探针全过，但随后串行正式调用仍出现TLS失败，说明降低并发不能保证FHL稳定。为完成负责人要求的全量诊断，采用最多8个相互隔离的单组账本并行首遍；每组遇首个传输失败立即停止，随后仅按账本恢复该失败及未调用单元。并发只改善采集吞吐，不隐藏失败或改变答案选择。

预先比较：

1. Luna A的硬约束、方向和TSR相对DeepSeek A是否下降；
2. A/B至少一方错误的句数与真正的纠错机会；
3. DARC−Fields的TSR、方向、改正/改坏事件和路线regret；
4. DARC相对A是否净改善；
5. 等义组路线稳定性及schema/传输可靠性。

不得把“弱模型上提升更大”直接外推为主模型贡献。若Luna有错误而Terra/DeepSeek饱和，只能说明方法可能依赖基础模型能力区间；正式贡献仍需Terra和预先冻结的新开发压力集支持。

## 2. 下一轮开发压力集

当前八组主要是明确陈述、封闭类别和直接时间/顺序约束。下一轮从开发暴露池预先分层抽取，不根据任何方法既有输赢筛选：

| 层 | 目标现象 | 设计要求 |
|---|---|---|
| 组合硬约束 | 多POI、截止与顺序共同出现 | gold可由原句直接举证，独立人审 |
| 隐式偏好 | 不直接出现“quality/distance”词 | 保留原句证据，不把模糊项强标为数值真值 |
| 否定与让步 | “不要绕路”“即使更远也…” | 最小对照只改变一个语义因素 |
| 近边界规划 | 相近质量/距离或关闭时间临界 | 图由结构规则构造，不按DARC表现搜索 |
| 等义扰动 | 句式、信息顺序和指代变化 | 四表达保持同一人工意图 |

建议规模为12个开发语义组、48句。每层至少覆盖2组，允许一组属于多个层，但分层标签在调用前冻结。先采A/B共96次；若A/B至少一方出现不少于4个不同语义组的真实错误或分歧，再执行四复核的完整配对比较。该门槛只决定是否值得花复核预算，不改变样本、标签或报告内容。

### 现有候选资格检查

为避免按模型结果选择，先固定尚未进入八组诊断的`pilot_09`–`pilot_20`作为12组候选。机器审计表明它们可覆盖密集POI、多个依赖和截止时间组合，但没有清晰的隐式偏好或偏好否定/让步层；`pilot_11`与`pilot_17`还存在文本表达“balance”而标签为`quality_first`的支持风险。因此这12组当前状态为`NOT_ADMITTED`，不能直接调用模型。资格证据见`results/v5/development/stress12_candidate_qualification_20260910.json`。

下一步先对48句做人审，并在开发暴露池中预先构造至少各2组隐式偏好、否定/让步最小对；这些新项必须与母句同属开发split。满足五层覆盖后才生成96次A/B调用账本。

一轮允许的修改范围仅限：澄清复核提示中的“原句是最终语义依据”和schema示例；不改变候选提示、图、gold、方法输入层级或评价阈值。旧提示与新提示均保留，修订理由必须来自错误类型，不得来自挑选DARC获胜输出。

停止条件：

- Luna与压力集仍没有足够纠错机会；
- DARC相对Fields没有净纠正，或相对A增加任务错误；
- 规划反馈持续诱导模型改变原句明确偏好；
- 一轮提示修订后仍无增量。

满足任一实质停止条件后，不扩到未见测试；保留负结果并重新审议研究问题。
