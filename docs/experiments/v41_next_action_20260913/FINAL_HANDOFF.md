## 2. 核心方法修复与严格无泄露契约 (v4 整改落实)

本次 v4 整改全面落实了同行审计与验收提出的全部规范：
1. **彻底移除门控与 $\Delta U$ 中的 Gold 信息**：
   - 保护标记 $h$ 与跨效用 $\Delta U$ 严格仅使用 Candidate A 与 Candidate B 的模型预测输出及求解器内部评估 (`ev_internal_a`, `ev_internal_b`)。
   - 保证系统在决策“是否复核”时处于完全的测试时状态（Test-Time），**绝对不接触 `gold_hard`**。
   - `gold_hard` 仅作为最终被选定路线的离线基准质量核验依据。
2. **依赖结构传递闭包比对 (`Intent.closure()`)**：
   - 在保护标记 $h$ 的依赖拓扑比对中，调用 `closure(int.dependencies)` 规范化偏序闭包，避免因等价传递边（如 `[A, B], [B, C]` 与 `[A, B], [B, C], [A, C]`）引发误报。
3. **彻底解耦重放哈希自指 Bug (Decoupled Canonical Replay Hash)**：
   - 根因分析：原重算脚本将当前的 Git Commit 写入指标文件，而 canonical metrics hash 又包含了整个指标文件。一旦提交代码更改，Git commit 变动导致重放哈希必然失配。
   - 解决方案：`compute_canonical_metrics_hash` 仅对真正的不变量结果（数据集校验摘要、审计总结、预算对比结果、系统层结果）进行 SHA-256 计算，完全排除 `git_commit` 与 `timestamp`。
   - 代码溯源绑定：在 `manifest.json` 中独立固化 `eval_script_sha256`、`backend_sha256`、`prompts_sha256` 字典以及 `config_sha256`，确保实验环境与代码资产的双向严谨追溯。
4. **冻结 Bootstrap 协议与补齐 DARC − B3 区间**：
   - 严格遵循冻结协议（`AGY_NEXT_ACTION_DS_QWEN_TRANSFER_20260913.md` line 79）：设定重采样次数 **B=2,000**，固定随机种子 **20260912**，基于 35 个语义簇。
   - 完整报告 DARC 与 B4、B3、B0 之间的效用差与波动率差 95% 置信区间。
5. **系统层 40 条原始指令独立重新分配 4 次复核**：按 10% 预算直接在 40 条 V0 指令上进行 DARC、B4 和 B3 调度对比。
6. **强防篡改非零退出码机制**：输入数据、场景或尝试文件被篡改时，脚本在执行入口直接中止并抛出明确非零退出码（Exit Code 2: raw attempts 篡改, Exit Code 3: utterances 篡改, Exit Code 4: scenarios 篡改, Exit Code 5: replay 校验失配），绝非测试代码事后比对。
