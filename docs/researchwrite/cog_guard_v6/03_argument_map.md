# Argument map

- Tension: structured output can be valid while the accepted ontology value is unsupported or non-executable.
- Central question: can explicit evidence, ontology validation, conservative abstention, and post-parse consequence checks improve semantic fidelity without trading away task success?
- Thesis to test: COG-Guard will improve executable semantic fidelity relative to JSON-only and ontology-only baselines; this is a hypothesis, not a result.
- Supporting arguments: current Travel mismatches are concrete; invalid types and transport failures are separable; compiled constraints show ontology values alter execution semantics.
- Counterarguments: errors may be model-specific, ontology labels may be incomplete, abstention may inflate apparent fidelity, and formatting gains may not improve tasks.
- Final move: proceed only through pre-registered gates that distinguish format, semantics, and task outcomes.
