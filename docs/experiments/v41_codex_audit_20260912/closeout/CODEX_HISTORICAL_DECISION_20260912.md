## 本次核验事实

1. 历史指标 JSON 的 SHA256 与报告一致：6942bed0f09cef1053a44f3f6b9e4e44b0747261bfdc0bbc140d611ee65db03c。哈希相同证明引用一致，不证明统计解释正确。
2. 10% 配额历史全 160 组：mini 相对随机降低 7.09 pp，相对 B4 降低 6.04 pp；Luna 相对随机降低 1.09 pp，相对 B4 降低 1.25 pp，但 CI 均跨零；Sol 相对随机降低 0.97 pp，但 **相对 B4 升高 1.25 pp**（DARC 25.00%，B4 23.75%，差值 CI [-0.0031, 0.0281]，不显著）；Gemini 相对随机降低 0.30 pp、相对 B4 为零。主表不能只列随机基线而淡化 Sol 的 B4 反例。
3. DS 640 条中有效 A/B 双候选 411 条，其内部 h=2；但 src/gating.py 明确规定任一候选缺失亦触发 h，按全分母生产函数计算 **h=231/640**。Qwen 有效双候选 578 条，内部 h=0，但全分母 **h=62/640**。因此 DS 的 10% 配额 K=64 不可行，Qwen 可行但只剩 2 个非保护名额；Qwen 的 5% 配额不可行。新报告把条件子集计数放到全分母上，是实质错误。
4. DS 的 226 条无有效 A 包含 **225 条空 raw + 1 条非空 raw 但无有效候选**，不能全部称网络未送达。旧 233 次 transport failure 是调用层计数，不能直接等同 226 条输入失败。“有效候选上的 TSR=100%”仅是条件硬约束任务成功，不能推出语义完美或完整服务成功100%。
5. 历史新增 JSON 仍显示 mini usage_missing_count=3200、token=0、candidate_match_count=0，说明使用了尚未兼容历史字段的旧检查路径；这不代表真实零 token 或所有候选无效。应沿用 v2c 已修正的 telemetry 和强绑定方法，不重新引入旧口径。当前历史 clean146 在 evaluate_cohort 中重新分配配额，不能冒充全160固定政策切片。
6. FINAL_AUDIT_SUMMARY 中“五模型同一40组”“模型演进阶梯”“DARC防御改坏”“纯净确认集”“待人审”均不是当前有效表述。mini 来自历史160；Luna的DARC也改坏一例；32/8是已识别暴露簇的事后分层；人工审核已通过。新报告“Haiku扩到160必然仍是5%-6%”没有证据，不能以此决定停止。

## 论文定位与停止规则

研究问题仍是“决策后果是否比语义差异更适合分配有限复核预算”，不是模型能力排名，也不是保证复核无损。主要正证据为 mini；Luna 两批结果不一致需要公开；Sol、Gemini和Claude用于界定适用范围。基础 Flip 高不自动意味着 DARC 有效（Sol即为反例）。

停止扩量的理由是当前已有多模型、同数据历史面板和跨协议诊断，足以支撑有限 EI 实证研究的证据结构；不是已经证明跨模型普适，也不是预测新数据不会改变结果。若作者坚持普适优越性，现有证据不支持，不能靠改措辞补足。
