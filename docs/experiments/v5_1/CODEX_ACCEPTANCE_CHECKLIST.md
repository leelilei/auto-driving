# DARC-Route v5.1：Codex独立验收清单

日期：2026-09-09。依据：[指导书](EXPERIMENT_GUIDE.md)、[Proposal](../../plans/proposal.md)。本文件列出待验收项，**没有一项因写入文档自动通过**。

执行者在每批 `SELF_CHECK.csv` 填写 `check_id,stage,self_status,evidence_path,counts,notes`，状态为PASS/FAIL/NOT_RUN/BLOCKED；不能填独立验收结论。Codex另建 `CODEX_REVIEW_<date>_<batch>.md`，记录复查命令、抽样和结论，不改历史报告。

## 4. S5/S6：完整实验与结论验收

| ID | 检查内容 | 所需证据与Codex动作 |
|---|---|---|
| E01 | 全量完整性 | 独立按账本重计各角色、图、repeat；所有失败和未完成有解释 |

| E05 | 指标独立重算 | 逐例检查器→TSR/GTSR/L→主表，核查共同成功与全方法参考集分母、失败惩罚敏感性 |

| E07 | 消融与重复 | 全部预定项完成或有测试前范围修订，不能挑最好repeat；只重采review不称端到端重复 |
| E08 | 原句与跨图行为 | 盲审抽样与真实审核记录，四格分布、unclear和漂移诊断齐全 |

| E11 | 真run破坏测试 | 在副本重做R05；篡改后成功退出是阻断项 |
| E12 | 可移交包 | 全部文件清单、源码/依赖、raw/输入/图/提示/命令齐全，无密钥；SHA校验不代替E01–E11 |
