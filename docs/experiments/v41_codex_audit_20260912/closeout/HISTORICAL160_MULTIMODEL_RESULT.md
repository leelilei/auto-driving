# 历史 160 组多模型面板：统一离线结果

日期：2026-09-12。该面板将 mini、Luna、Sol、Gemini、Haiku 和 Sonnet 的历史测试集运行置于同一离线评分口径中。每个模型是独立面板；不与 E2 40 组拼接，也不据此做模型能力排名。

## 固定口径

- 数据：160 组、640 句、每组 4 个等义变体；每个历史运行的 640 个 ID 与原始文本逐字核验。
- 主比较：10% 复核配额（64/640 请求），结构保护项相同；DARC、B4（语义权重差）和 B3（20 个固定随机种子）在同一请求集合上比较。
- 主指标：所有方法均任务成功的请求对上的路线 Flip。差值为 DARC − 基线，负值为 DARC 较低；组 bootstrap 2,000 次，种子 20260912。
- 原始采集为主表。Haiku/Sonnet 的独立恢复结果不写回主表，不改变失败分母。

## 结论与限制

1. mini 是唯一在 B4 和 B3 两个比较中都呈现清晰稳定收益的历史运行。它可以作为机制正例，不能代表所有模型。
2. Luna 对两个比较均有正向点估计，但区间跨零。Sol 对随机基线略好，却劣于 B4；这是重要反例，主文必须并列展示。
3. Gemini 与 Sonnet 的基础 Flip 已很低，对 B4 没有增量；它们支持适用边界，不能被解释成 DARC 已达到理论最优。
4. Haiku 相对 B3 有小幅稳定性信号，但 DARC 选择了 `test_008_v3` 后出现 1 个任务改坏。完整分母失败惩罚损失从 B0 的 0.004005 降至 0.003946，但此数依赖损失系数 1，仍不得写成无损提升。B4 在这次选择中没有改坏。
5. 缺失调用不会被悄悄填成成功：Luna 有 2 条缺失 review 记录；Gemini、Haiku、Sonnet 分别有 1、6、1 个所选 review 回退。存在缺失 token 的模型，其方法总 token 记作不可得，而不是零。
6. Haiku/Sonnet 采集协议含历史 Claude 解析适配。主面板严格重放当时的解析器：出现多个 JSON 块的原始响应仍视为失败，不能由新的宽松解析器改写。恢复结果仅用于服务/格式敏感性，不替代主结果。
