# 论证图
已知：语言解析能接规划，复核与工具反馈已有。矛盾：逻辑上可行的路线也可能源于误读；参数分歧与实际后果不一致，且复核可能改坏。问题：在相同复核机会下，显式呈现候选解释的规划后果，是否能帮助定位并纠正影响决策的误读？方法：两候选→精确规划与单字段替换诊断→结构化对比报告→一次原句证据复核。验证：同候选/同次数/实际token报告，字段差异对照、通用约束反馈对照、去掉对比报告消融，同意图跨图配对。反证：复核无净收益、输给字段对照、对比反馈诱导偏好漂移。边界：合成图、校准效用、共同误读与语义模糊、不保证跨任务。

量化证据链：公开解析指标连接既有研究 → V0历史输出重评分提供外部参照 → 同模型原文提示基线及信息对照重跑隔离方法增量 → 明确TSR百分点、损失降幅、净纠错和成本 → 仅在符合外部协议且覆盖强基线时讨论限定指标SOTA。
