# 24例统一提示的信息层级消融

2026-09-10。负责人授权推进下一轮机制验证。性质：受控开发实验，非确认性测试；论文写作CLOSED。

## 冻结协议

完整沿用上一轮24个案例，来自8个已暴露母意图；不按输赢选例、不重新造图、不改gold。每例3种信息、2次独立调用，共144个逻辑请求。重复不增加独立语义样本数。

| 信息组 | 模型收到的补充信息 |
|---|---|
| fields | 不同字段名称 |
| route_order | 同样字段名称，加A/B候选路线的类别访问顺序 |
| full | 同样字段与路线顺序，加距离、质量、时间、可行性、交叉约束、单字段替换后果等原有完整决策信息 |

所有组共用同一复核指令、schema、证据要求、候选、原句，均明确两候选可共同错误。原句仅出现一次；full移除报告内重复原句、原始候选副本及候选证据。保留单字段替换的混合候选用于表达规划后果。route_order直接截取full的类别顺序，不添加gold或正确性暗示。fields也提醒不得从地图推断偏好，保证指令文字一致。

模型沿用DeepSeek官方`deepseek-v4.1-flash-expires-on-0910`配置，temperature=0，输出上限1600，4路并发，先用首个冻结请求检查鉴权。每个请求自动重试0，传输失败最多恢复一次，全轮恢复最多8次；401/403停止后续批次。schema错误不得重试，采用原有回退A规则，同时披露原始输出错误。

候选位置保持原轮平衡，调用组顺序按案例和重复轮次确定性轮换，不使用模型结果。SHA256只用于资产完整性校验，不参与方法决策。

## 指标与判断

主比较full−route_order：硬约束与偏好方向同时正确。另报route_order−fields、full−fields，路线TSR、相对固定A的纠正/改坏、provider tokens、逐重复与逐错误族结果。方向映射沿用现有协议：w>0.6为质量优先、w<0.4为距离优先，其余均衡；不把0.75等校准权重称为原句数值真值。

先检查144请求有完整终态且无未解决传输失败，再形成主表。正反配对事件均保留。当前规模仅描述性诊断，不做显著性或自然分布提升主张。

若full只优于fields而不优于route_order，优先保留简化路线呈现假设，不宣称数值决策后果有效。若三组饱和，本轮不支持额外信息增量。若full稳定优于route_order，才值得继续检验规划反馈机制和自然错误分布。两次重复不足以排除采样波动。

full增加的不仅是数值，还包括交叉约束和替换结构；本轮不能进一步归因到某一数值指标。输入长度、重复结构和实际推理token仍不相等，不能声称同成本因果优势。新统一指令也改变了上一轮的提示，因此不把跨轮分数变化视为单一因素效果。

## 机制解释与下一步判断

这一轮支持“路线类别和访问顺序的呈现可能帮助复核”作为下一步假设。两轮重复中route_order都高于fields，差异跨多个母意图；但重复次数少，尚不构成自然错误分布上的结论。

完整报告相对route_order的四个不一致单元逐项核对如下：

- `extra_order_4`第1次：Full正确；Route order输出JSON括号不完整，回退错误A。这是格式可靠性差异，不是已证实的规划语义增量。
- `missing_deadline_3`第2次：Full将原先距离优先改成均衡，Route order正确，Full失分。
- `reversed_order_4`第2次与`common_error_4`第2次：Full正确、Route order错误。

后三项全部来自`pilot_06`。因此，排除格式失败单元的描述性配对诊断仅剩2胜1负，净1例，且集中在一个母意图；这是辅助分析，不替换完整主表。Full的4个语义错误也都来自pilot_06，将“complete everything efficiently”解释为均衡。既有审核方向标签保持不变；该短语是否足以唯一支持距离优先，应在未来新数据设计时明确，不能依据本轮答案事后改gold。

Full更高的正确率同时伴随3次改坏正确A，Route order为2次。不能只报告纠错数而隐去改坏。两候选均正确控制组均为8/8，但其他候选一正一错时仍可改坏。

研究决策：保留简化路线顺序反馈作为候选，完整报告作为消融对照；当前不支持把数值规划后果、效用计算或单字段替换宣称为已证实的核心贡献，不据此启动正式全量测试或论文。下一轮优先在预先定义的新开发规则族上检验自然候选错误中的路线顺序反馈收益，并加入“仅把候选依赖写成自然语言”的简单对照，辨别是否必须运行求解器。新任务若仍饱和，就重新审议研究方向，避免持续围绕这8个意图调参。
