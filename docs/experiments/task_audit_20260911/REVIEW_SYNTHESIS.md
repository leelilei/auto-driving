## 共识优点

三份报告均认可，区分“规则是否忠实”与“求解器是否解对已给规则”有领域价值。固定复核机会、显式语言对照、公开事实和 gold 的接口隔离，以及保留不利结果，都是应保留的设计。EI 论文可以贡献一个扎实的窄机制或可迁移诊断，不必承诺全球 SOTA 或自动驾驶安全效益。

## 其他重要问题及真实差异

R1-M2 将规则与对象成功错位、回退改变归因列为阻断；R3-M2 也独立提出这个问题，但判为非阻断，强调用场景变化补足用户价值证据。R2-M2 同样提醒澄清后任务同分不代表语义等效。这是共同识别的问题，但严重度存在差别。

R1-M3 单独把统计独立性与标签证据列为重大阻断。R3-m2 则将调用独立性字段表述列为次要问题，因为包内没有证据显示已经错误计算显著性。综合意见采用前者的未来证据要求，不据后者的字段名推断作者已经犯了统计错误。

R2 对近邻原创性和数据许可最敏感，R3 更关注小型 DSL 与公开完整旅行任务之间的读者价值，R1 更关注终点能否识别机制。这些是定稿后观察到的侧重点，不是事后人为制造分歧。

## 主审补充核查

**Fair30 的负责人批准确已存在。** [负责人凭证](../scene_pilot12/FAIR30_OWNER_APPROVAL.json)记录本对话用户明确批准 30 个案例，并绑定数据 manifest。原始 summary 保留 PENDING 是历史快照，不等于现在仍无人审核。三名评审包中缺少该凭证，其意见准确限于材料不可评估；不修改冻结报告，而在此补足事实。该批准不覆盖旧 SceneRule30/Glossary，也不等于接受方法有效性或启动论文。

**成本措辞应收紧。** 接口澄清后语言和证据组已记录 token 分项总和分别为 33,383 和 51,085，比例约 1.53；语言组另有 1 次 usage 未知。不能称精确总费用增加 53%，也没有完整共同 Direct 成本和供应商计费权重。此前概览中的“成本更高”应理解为记录到的 token 负担线索。

**新增任务审计不属于评审共识。** 主审补查 ChinaTravel、形式化求解器工作与 CORAL，建议先核验 ChinaTravel 原始自然语言模式，详见 [TASK_AUDIT.md](TASK_AUDIT.md)。这不是三名评审已完成的运行复现或穷尽文献证明。

## 小修清单

- 用单一日期状态入口替代多个“最新”；历史方案和历史执行状态明确归档。
- 同时列出案例数、重复数、方法调用数，避免把 180/120 次决策当独立任务数。

- 成功率差使用百分点，未知 usage 和非同场对照如实披露。

## 综合判断与下一步

保留项目，暂停当前事实表复核的扩量。历史 v5.1 的精确方法没有被后续场景实验严格否定，但也没有由这些结果得到验证；不建议只为保住 DARC 名称继续投入。

建议先以公开任务的语义忠实性诊断作为候选问题，完成评分器、输入权限与强基线的可执行小批次核验，再决定是否存在值得提出新方法的缺口。不能把当前 30 例事后诊断直接写成广泛负结果论文。具体候选边界见 [proposal 重新定位](../../plans/PROPOSAL_REASSESSMENT_20260911.md)。

当前不支持的主张包括 DARC 独特收益已成立、所有计算反馈无效、两种复核统计等效、已取得公开 benchmark SOTA、外部环境已经准备完成。实验先行原则继续生效，论文写作 CLOSED。
