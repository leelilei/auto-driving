# ChinaTravel 与 proposal 的对应及投入判断

2026-09-11。依据：[历史 proposal](../../plans/proposal.md)、[候选重新定位](../../plans/PROPOSAL_REASSESSMENT_20260911.md)、[本轮实际结果](CHINATRAVEL_CLOSEOUT_20260911.md)。

**判断：ChinaTravel 可以继续作为候选任务，优先使用显式解析＋RuleNeSy 后端；尚不能称原 proposal 已迁移完成。** 当前已消除“工具和评价根本不能运行”的主要疑问，不需要继续把 Act 的行程生成能力作为前置门槛。

## 核心对应

| 原 proposal 的对象 | ChinaTravel 可操作对象 | 已完成 | 尚需解决 |
|---|---|---|---|
| 用户原句 x | 原始 nature_language | 真实请求完整保留，gold 分离 | 独立语义审计，不以 DSL 字符串相同代替含义一致 |
| 候选解释 A/B | 结构化预测约束 | 已有真实的五字段解析及逐字段原句依据，能编译到官方受限 DSL | 未形成两个自然生成候选；当前无五字段误读样本 |
| 固定规划器 | RuleNeSy 本地用餐状态修复版 | 真实环境查询、原始成功计划、官方 all-pass 1/1、可追溯工具轨迹 | 非精确最优求解器，不能照搬原方案的最优 regret 主张 |
| 候选后果与交叉检查 | 相同后端下的约束满足、可行路线、费用、耗时 | 实际行程对真实预测预算通过，对构造的 10 元预算失败 | 这里只验证检查接口；构造反例不是自然误读，也不是复核有效性证据 |
| 同一次复核的信息干预 | 文字字段反馈 vs 计算后果反馈 | 未执行 | 必须同一初始候选、同后端、同复核机会，隔离信息增量 |
| 任务评价 | 官方 schema / commonsense / hard 交集 | 原始 dev 评价字段兼容修复，固定分母、断网评分可用 | 任务通过不能自动当成完整语义忠实 |

原 proposal 的核心问题仍可保留：**规划后果信息，相比充分说明的文字反馈，是否产生额外净纠正收益？** 目前只是打通提出这个问题所需的窄接口，没有得到肯定或否定结论。

## 三个预先固定 dev 案例的映射边界

这些案例沿用既定回归例与 medium/human 字典序最小 UID，不按模型输赢更换。

| 案例 | 原句中的要求 | 当前接口覆盖 |
|---|---|---|
| e20241028160248698752 | 上海→杭州、独自、一天、1500 元 | 五字段全部覆盖；真实单例已通过，含宿主通用输出请求处理 |
| e20241028160842228543 | 上海→北京、与朋友、三天、6000 元、主要地铁、一间单床房 | 城市/人数/天数/预算可表达；“主要地铁”的量词含义及房型/房数需扩展和核对，不能直接丢弃后跑分 |
| h20241029143447759844 | 上海→苏州、两人、三天、轻快自由行、不要特种兵 | 城市/人数/天数可表达；预算未给，节奏要求无唯一数值阈值，不能自造预算或活动数来声称完整解析 |

medium/human 在本轮没有模型采集。它们提醒我们：不是所有旅行原句都能用五字段接口覆盖，也不是所有语义都能直接从官方 DSL 获得充分评价。不能把后一类模糊偏好按任意规则判成误读。

## 下一阶段应做的工作及停止条件

1. 先对开发数据做语义覆盖审计：区分可明确标注的要求、模糊偏好、当前接口不支持的具体限制。保持完整原句与原始 ID，不能按 DARC 输赢或模型错误选例。
2. 为确定性的交通、房型、房数、餐饮要求补齐结构化接口和官方 DSL 编译，单独核验评价含义。遇到“主要”“轻快”等表述先确定可辩护的评价边界，不能替用户创造数字阈值。
3. 用固定解析＋规划器小批检查是否出现自然语义错误。若语言基线已正确，或失败主要仍是搜索/数据/格式问题，不追加 DARC 来制造可改进空间。
4. 只有确认目标错误存在，才实现同候选的文字复核与计算后果复核对照；若简单文字反馈同样有效，应接受复杂反馈没有必要。

本轮不开展上述新增模型实验，也不自动转成 60 例。现在可以停止通用接入修复，把后续投入集中在语义覆盖和最小方法对照。若这些步骤表明 ChinaTravel 主要衡量搜索、无法独立评价目标语义，就停止它作为 DARC 主验证任务的用途，而不是继续扩充旅行 agent。

原方案的 HIPP-DC、跨图设计、精确效用损失与两候选实验并未被本轮替代。换成 ChinaTravel 仍需明确修订实验协议；不把本轮工程通过当作新 proposal 获批或论文主张成立。
