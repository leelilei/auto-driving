## 3. 已修复的实验正确性问题

1. **未知 POI 静默被过滤。** 原求解器可把非法请求当作空请求成功返回。现在严格拒绝未知类别，失败显式记录。
2. **空请求不检查时间。** 现在直达路线也检查截止时间。
3. **依赖别名未统一。** HIPP 全部数据中有 223 条记录的依赖含空格别名。现在 `shopping mall` 与 `shopping_mall` 在 schema/预处理统一，未知依赖与循环依赖不会被删除。原始 HIPP 和已抽取的原始 Pilot 保留，标准化发生在处理层。
4. **数值合法性与平局处理。** 拒绝 NaN、越界权重和非法时刻；采用完整 POI ID 元组确定平局。图序列化保留距离缩放常数精度。
5. **缺少独立 gold 检查。** 新增独立路线检查器，重新计算行驶、等待、停留、截止与顺序，并检查请求覆盖，不调用规划器的约束评价函数。
6. **调用预算字段未转发。** Chat Completions 客户端现在转发输出 token 上限，并有无网络单元测试覆盖。

Python 依赖锁定见 `9-AutoDriving-core/requirements-dev.lock.txt`。核心使用方法见 `9-AutoDriving-core/README.md`。
