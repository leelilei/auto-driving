# Gemini 3 Flash Travel 100 次诊断

## 分层结果

- 计划调用：100；唯一输入：60；预登记重复：40。
- 完整响应：79/100。
- 失败：21/100，其中 JSON/空正文失败 18 次，传输失败 3 次。
- 60 条唯一输入中，48 条有响应，40 条 schema 合法，8 条 schema 类型非法。
- 8 条 schema 非法主要是 `cuisine` 或 `attraction_category` 输出为单元素数组，而合同要求字符串或 null。
- 在 40 条 schema 合法的唯一响应中，已审计字段 40/40 匹配；未观察到额外语义 mismatch。

## 解释

Gemini 3 Flash 暴露了两个不同层次的问题：

1. 通道/响应稳定性不足（21/100 失败）；
2. 输出合同不稳定（唯一输入 8/48 响应违反字段类型）。

它没有在合法输出子集上显示比 DeepSeek 更多的语义错误。不能把数组形式强行转换成字符串后计为成功，也不能把传输失败算作语义失败。

## 决策

这批结果支持继续修复 Travel 的输入/输出合同诊断，但不支持启动阶段 5，也不支持宣称弱模型证明了 DARC 架构收益。下一步若继续，只做预注册的 schema 约束/ontology 映射小实验，并保留原始失败分母；不再扩大 Gemini 调用量。
